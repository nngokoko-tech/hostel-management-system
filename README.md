# Hostel Management System

## Overview
A web-based system designed to simplify hostel accommodation management.

## Features
- Student registration
- Room management
- Bed allocation
- Student accommodation records
- Search and management of hostel records

## Technologies
- PHP
- MySQL
- JavaScript
- HTML
- CSS
- Bootstrap

## Installation
1. Clone the repository.
2. Place the project in the XAMPP htdocs directory.
3. Create the MySQL database.
4. Import the database SQL file.
5. Configure the database connection.
6. Start Apache and MySQL.
7. Open the application in a web browser.
